# I5（P2）：面向决策的前端工作台

## 目标

将当前以数据集、任务和实验列表为中心的界面，组织为清晰的实验决策流程。普通用户
能一键获得可信端到端基线；研究用户仍可使用现有 KG、上下文和证据选择消融实验。

## 用户故事

- 作为首次使用者，我想从生成一个场景到得到可解释的基线结果，而不需要理解全部实验脚本。
- 作为选型者，我想在一处比较质量、延迟、成本与稳定性，并了解结果是否可比。
- 作为研发人员，我想从失败汇总跳到单题完整 trace，继续做深入消融。

## 功能需求

### FR-5.1 信息架构

评测控制台重组为六个视图：

1. 数据场景：生成、版本、场景分布、oracle 覆盖；
2. 评测环境：已发布的环境档案及实际配置；
3. 评测计划：数据集、环境、实验类型、预算和可比性预检；
4. 运行与对比：队列、运行状态、质量/成本/延迟对比；
5. 失败诊断：失败漏斗、分类、逐题 trace；
6. 研究实验室：现有上下文、KG、证据选择、规模等高级消融实验。

### FR-5.2 最短可信路径

- 首页提供“一键端到端基线”：选择数据场景与已发布环境后，显示即将执行的阶段、
  预计资源和隔离说明。
- 前端在启动前调用可比性与环境预检；阻塞错误不可绕过，风险项需显式确认并写入 run。
- 队列页展示认领状态、运行阶段、失败原因、取消按钮和恢复/清理建议。

### FR-5.3 对比与推荐呈现

- 对比页按实验类型分组，只允许选择 I3 已判定可比的运行。
- 同时展示质量、延迟、成本、失败分布和置信区间；排名依据与权重必须可见且可调整。
- 不满足样本量或稳定性阈值时显示“暂不推荐”，而不是输出最佳模型。

### FR-5.4 诊断体验

- 使用阶段漏斗展示：解析、索引、召回、最终上下文、回答、评分待复核。
- 支持按场景、题型、失败分类和配置臂筛选，并从任一统计值跳转到 case trace。
- 展示 oracle 证据、候选上下文和最终上下文时提供脱敏、长度提示和安全访问控制。

### FR-5.5 可访问性与操作质量

- 所有任务状态有文本、颜色和非颜色提示；长任务支持刷新恢复，不依赖单页内存状态。
- 关键破坏性操作（取消、删除 workspace、清理运行）必须显示范围与后果，并使用确认步骤。
- 新流程需有前端组件测试及端到端测试：创建计划、启动、取消、服务重启恢复、比较限制、
  诊断跳转。

## 非目标

- 本迭代不重新设计 LightRAG 主问答控制台。
- 不以视觉重做替代 P0/P1 的数据可信性和诊断能力。

## 验收标准

- 新用户可在不进入“研究实验室”的情况下创建并完成一个端到端基线。
- 对比页无法把 legacy、不兼容或配置不完整的运行并列排名。
- 从失败分布图点击任一分类，可在两次交互内看到对应 case 的完整诊断证据。
- 前端 lint、组件测试和核心评测流程端到端测试均通过。
